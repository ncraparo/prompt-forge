# prompt-forge
A prompt builder for media generation.
——————————————————————————
Info:<br>
The Build tab assembles a prompt from subject, action, setting and style chips. The Enhance tab takes a rough prompt and adds only what it's missing, such as lighting, camera, mood, palette or quality terms. Video mode adds action, camera movement and clip length.

Output formats are natural language (for Sora, Veo, Runway, Flux or DALL·E), Midjourney (--ar and --no), and Stable Diffusion tags with a separate negative prompt.
